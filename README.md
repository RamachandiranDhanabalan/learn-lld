# Low-Level System Design — Interview Preparation

A structured 80-day LLD course for a Java backend engineer (9+ YOE).

## How This Repo Is Organized

```
topics/          → Reusable knowledge base (OOP, SOLID, Patterns, UML, Concurrency)
problems/        → Full LLD problem solutions with diagrams and code
daily-learnings/ → Day-by-day journal (references topics/, includes Q&A, quiz, feedback)
quiz/            → Standalone quiz bank for revision
resources/       → Master resource list + trade-off matrix
```

## Quick Start

1. Open `COURSE-PLAN.md` for the full 80-day curriculum
2. Say "Day N" in your AI chat to get the lesson (use `PROMPT.md` for new sessions)
3. After each day, fill in `daily-learnings/day-XX.md`
4. Code goes in `problems/<problem-name>/`
5. Notes and concepts build up in `topics/`

## Core Principles

- **Problem → Pressure → Pattern** — understand WHY, don't memorize
- **Implement over read** — 25% reading, 60% coding, 15% review
- **Trade-offs always** — What I chose / Why / Alternative / When it breaks
- **Concurrency from the start** — not an afterthought
- **Appropriate simplicity** — knowing when NOT to use a pattern matters
